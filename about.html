About telex

telex is tooling that sets an image in running text.

Summary

Spot's ASCII effect draws each cell as a character chosen by tone. Here every character is the next letter of a real text, so the image is built out of prose and each cell reads through its text one letter at a time. Several texts can run at once, one per tone band.

Description

The image is divided into a grid and each cell takes a tone. Tone bands choose which text a cell draws from, and an advance mode decides which letter it shows and how that changes. A tilt control lays the grid on a plane that recedes, so the letters can be read in columns moving to the front.

This is a prototype for settling the design. It uses Spot's demo images and Form's look.

How it's made

Plain HTML, CSS and JavaScript, drawn on a canvas, with no server and nothing to install.
